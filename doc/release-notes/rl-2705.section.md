# Nixpkgs 27.05 (2027.05/??) {#sec-nixpkgs-release-27.05}

## Highlights {#sec-nixpkgs-release-27.05-highlights}
<!-- To avoid merge conflicts, consider adding your item at an arbitrary place in the list instead. -->

- `nodejs` and `nodejs-slim` now default to Node.js 26 LTS instead of 24 LTS.
  Review the [Node.js 26 changelog](https://github.com/nodejs/node/blob/main/doc/changelogs/CHANGELOG_V26.md) for breaking changes.

  Node.js stopped bundling Corepack in version 25, so `nodejs` no longer provides a `corepack` executable.
  Add the `corepack` package where you need it:

  ```nix
  pkgs.mkShell {
    packages = [
      pkgs.nodejs
      pkgs.corepack
    ];
  }
  ```
